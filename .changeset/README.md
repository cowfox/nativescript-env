# Changesets

This folder is managed by [Changesets](https://github.com/changesets/changesets).

To add a changeset, run `pnpm changeset` (or `make changeset`) and follow the prompts.

See the **Development & Release** section of the [README](../README.md) for the full
versioning + publish flow (`make cut` → `make pre` → `make changeset auto` → `make release push`).
